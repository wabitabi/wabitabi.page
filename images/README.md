# 画像フォルダ（public/images/）— 写真の入れ方ガイド

サイトの写真はすべてこのフォルダに置きます。
**下の表のファイル名で画像をアップロードするだけで、その場所に自動で表示されます**
（コード変更は不要。まだ無い箇所は仮のイラストが表示されます）。

## アップロード方法（GitHubのWeb画面）
1. このフォルダ（`public/images/`）を開く
2. 右上「Add file」→「Upload files」
3. **下の表のファイル名にリネームしてから**ドラッグ＆ドロップ →「Commit changes」

## 差し替え・追加のルール
- **上の「まず用意したい写真」は、表のファイル名で置くだけ**で反映されます
  （置くまでは仮イラストのまま。サイトが崩れることはありません）
- 実績記事やお知らせ用に画像を増やす場合も、このフォルダに
  内容がわかる英数字名（例：`works-danang-vol1.jpg`）で置いてください
- 推奨：横1600px以上／1枚500KB以下／形式は `.jpg`（写真）・`.png`（図）・`.svg`（アイコン）
- ヒーロー（トップ全画面）は現在「空の写真」。動画にしたい場合は別途ご相談ください
