# 画像フォルダ（public/images/）

サイトで使用する写真・画像は、すべてこのフォルダにまとめます。
ここに置いたファイルは `https://サイトURL/images/ファイル名` で参照されます。

## 写真のアップロード方法（GitHubのWeb画面から）

1. GitHubでこのフォルダ（`public/images/`）を開く
2. 右上の「Add file」→「Upload files」を選択
3. 下記のファイル名に**リネームしてから**ドラッグ＆ドロップ
4. 「Commit changes」を押す

## ファイル名の対応表（サイト本体で使用中の5枚）

| ファイル名 | 内容 | 主な使用箇所 |
| --- | --- | --- |
| `photo-1.jpg` | 和室の窓辺で世界地図を広げる女性 | 私たちについて（創業ストーリー）、無料相談ページ |
| `photo-2.jpg` | 書斎で地球儀に触れる女性（夕陽） | 私たちについて（代表プロフィール） |
| `photo-3.jpg` | カフェでノートPCの地図を開く女性 | サービス（SNS PR事業）、実績一覧 |
| `photo-4.jpg` | 夕焼けの熊本城を見上げる女性 | トップのメインビジュアル（16:9ヒーロー）、サービス（くまもと留学相談室） |
| `photo-5.jpg` | ベトナムの路地で振り返る女性 | サービス（Wellbeing留学）、トップの事業紹介 |

現在は同名の `.svg`（photo-1.svg〜photo-5.svg）が仮のプレースホルダーとして
表示されています。上記の `.jpg` をアップロード後、`lib/photos.ts` の `src` の
拡張子を `.svg` → `.jpg` に変更すると、サイト全体に実写真が反映されます
（アップロードだけ済ませてもらえれば、差し替え作業はこちらで対応可能です）。

## 追加画像のルール

- 実績紹介・お知らせ用の画像を増やす場合もこのフォルダに置く
  （例：`works-2026-danang.jpg`、`news-summit.jpg` のように内容がわかる名前を推奨）
- 推奨サイズ：横1600px以上、容量はできれば500KB以下（表示速度のため）
- 形式：`.jpg`（写真）／`.png`（ロゴ・図版）／`.svg`（アイコン等）
